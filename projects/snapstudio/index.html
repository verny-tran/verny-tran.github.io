SnapStudio

A macOS studio for authoring presets, and the image SDK the apps render with.

Role

iOS engineer at SilverAI

Period

07/2026 – present

Platform

macOS 14+, iOS 15+

Source

Private · SilverAI

Stack

  • Swift
  • SwiftUI
  • Core Image
  • Metal
  • AppKit

SnapStudio is two things built together: an image-pipeline SDK — Core Image kernels, Metal shaders, the effect pipeline and its adjustment layer — that SnapEdit and RollieCam link, and the macOS app where the presets those apps render are authored.

What it carries

  • The effect pipeline and the .snapeffect format, with XMP import for existing looks.
  • A dark-only authoring console with Camera and Effect workspaces, producing .snapcamera and .snapeffect files.
