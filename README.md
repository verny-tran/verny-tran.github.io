# verny.com

Personal site of Trần Trung Dũng (Verny), served by GitHub Pages from the `main` branch at [verny.com](https://verny.com).

Plain HTML and CSS with no build step: edit `index.html` or `styles.css`, push to `main`, and Pages publishes it.

- `assets/resume.pdf`: the downloadable résumé. Replace it with a fresh export from Pages when the résumé changes.
- `CNAME`: the custom domain. Keep it, or Pages drops the domain.
